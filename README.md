# ARLAN — город, который слышит воду

Платформа раннего предупреждения о паводках для Петропавловска (река Есиль).
Город превращается в датчик: оптоволокно слышит дамбы, радиолинии сотовых операторов
меряют ливень, GNSS-станции меряют уровень реки и снег. ИИ сводит всё в прогноз и тревоги.

## Что внутри

```
arlan/
├── HARDWARE.md            ТЗ на железо (станция GNSS-IR)
├── firmware/              Прошивка станции и edge-скрипт оптоволокна
├── server/                API (FastAPI): вход и роли, SOS и диспетчерская, инциденты,
│   ├── app.py             оповещения с утверждением, сценарии, ИИ-ассистент (Claude + инструменты),
│   ├── arlan_api/         журнал действий, приём данных датчиков
│   ├── arlan_core/        модели: GNSS-IR, DAS, ливень по радиолиниям, прогноз, риск дамб
│   └── tests/             9 тестов
├── web/                   Фронтенд (React + MapLibre, 3D-карта): разделы по ролям, SOS-портал жителей
└── render.yaml            Деплой на Render (API + Postgres + сайт)
```

| Бригада | crew@demo.arlan.kz | своя задача, маршрут, статусы, GPS |

## Запуск локально

```bash
cd server && pip install -r requirements.txt
ANTHROPIC_API_KEY=sk-ant-... uvicorn app:app --port 8000     # без ключа всё работает, кроме ИИ
cd ../web && npm install && npm run dev                         # http://localhost:5173
```

## Деплой

1. Залить репозиторий на GitHub.
2. Render → New → Blueprint → выбрать репозиторий: поднимутся API, Postgres и сайт из `render.yaml`.
3. В сервисе arlan-api задать `ANTHROPIC_API_KEY` (и `ARLAN_API_KEYS` для датчиков).
4. Сайт можно держать и на Netlify: папка `web/`, переменная `VITE_API_URL` = адрес API.

## API для железа

Все `POST` требуют заголовок `X-API-Key` (ключи в `config/city.json` или env `ARLAN_API_KEYS`).

| Метод | Кто шлёт | Тело |
|---|---|---|
| `POST /api/v1/ingest/gnss` | GNSS-станция | `station_id, ts, mode (water/snow), reflector_height_m, water_level_m / snow_depth_m, n_arcs, quality` |
| `POST /api/v1/ingest/das` | edge у интеррогатора | `energies[канал][полоса]` за одно окно |
| `POST /api/v1/ingest/cml` | выгрузка оператора | `link_id, samples[{ts, tsl_dbm, rsl_dbm}]` |
| `POST /api/v1/ingest/dam_sensor` | датчики в дамбе (LoRaWAN) | `segment_id, phreatic_ratio, tilt_deg, moisture` |
| `POST /api/v1/ingest/level` | любой уровнемер / гидропост | `source, ts, level_m` |
| `POST /api/v1/ingest/weather` | метеопрогноз | `temp_forecast_c[15], swe_mm, reservoir_extra_release_m3s[15]` |
| `POST /api/v1/ingest/external_forecast` | Tasqyn / Flood Hub / GloFAS | `source, p50[15]` |

Остальное API (вход, SOS, бригады, инциденты, оповещения, сценарии, чат) описано в автодокументации: `/docs` на сервере.

## Переменные окружения

`DATABASE_URL` (Postgres; без него SQLite), `ARLAN_JWT_SECRET`, `ARLAN_CORS`, `ARLAN_SEED_DEMO` (1 = демо-данные),
`ARLAN_API_KEYS` (ключи датчиков), `ANTHROPIC_API_KEY` (ИИ-ассистент), `ARLAN_LLM_MODEL`, `TELEGRAM_BOT_TOKEN`.

## Что честно НЕ готово (до пилота)

- `config/city.json`: отметки гребней дамб, ноль поста, опасная отметка, трасса волокна, координаты —
  заполнители. Заменить данными акимата, ДЧС СКО и Казгидромета.
- `cml.py`: коэффициенты k/alpha приблизительные — сверить с таблицами ITU-R P.838-3.
- `forecast.py`: параметры снеготаяния не откалиброваны; нужны ряды уровня 2017, 2024–2026 гг.
- `das.py`: пороги подобрать на зимнем «фоне» реальной дамбы.
- Казахские тексты (сводка, демо-оповещение) проверить носителем языка.
- Пункты эвакуации и линии дамб на карте — условные, заменить данными акимата.
- Маршруты машин строятся через публичный OSRM (для пилота поднять свой); участки под водой определяются по рельефу SRTM.
- SMS-рассылка не подключена (нужен договор с SMS-шлюзом); Telegram работает при заданном токене бота.
- Карта на дашборде — схема, не в масштабе. Для пилота подложить реальную карту (OSM на своём сервере).
